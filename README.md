# Samuel Gomes - Art Portfolio & CMS 🎨

Este é um projeto de website pessoal e sistema de gerenciamento de conteúdo (CMS) desenvolvido para o ilustrador profissional **Samuel Gomes**. O objetivo é criar uma plataforma robusta para exibição de ilustrações, com um painel administrativo onde o ilustrador possa gerenciar suas obras de forma independente.

---

## 🚀 Status do Projeto

**Status: Em Desenvolvimento 🏗️**

Este repositório serve como meu laboratório prático para aperfeiçoamento em **Django**, **JavaScript** e boas práticas de desenvolvimento Back-end. O código está em constante evolução à medida que novas funcionalidades e refatorações são aplicadas.

---

## 🛠️ Tecnologias Utilizadas

- **Back-end:** Python & Django Framework

- **Front-end:** HTML5, CSS3 e JavaScript

- **Banco de Dados:** MySQL

- **Infraestrutura:** Docker & Docker Compose

---

## 🎯 Objetivos Principais

1.  **Galeria Responsiva:** Exibição fluida das ilustrações em qualquer dispositivo.

2.  **Painel Administrativo:** Área restrita para upload de imagens, edição de descrições e categorização de ilustrações.

3.  **Performance:** Otimização de carregamento de imagens de alta resolução.

4.  **SEO:** Garantir que o portfólio seja bem indexado em motores de busca.
